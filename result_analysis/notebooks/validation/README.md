# Validation Notebooks

- `rank_expert_sweep_validity_check.ipynb`: rank and expert sweep validity checks using the canonical workbooks.
- `mixed_followup_expanded_data_rerun_audit.ipynb`: audit of the expanded-data correction and reruns.
- `legacy_mixed_rank_expert_followup_validity_check.ipynb`: historical audit of the superseded original mixed follow-up; requires local pipeline outputs.
- `legacy_final_winners_96_validity_check.ipynb`: historical audit of the superseded initial final-winner training; requires local pipeline outputs.

The canonical statistical conclusions are in `../moe_study_final_analysis.ipynb`. Validation notebooks provide supporting operational evidence and are not alternative sources of selection decisions.
