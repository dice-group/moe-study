# Result Analysis Notebooks

- [`moe_study_final_analysis.ipynb`](moe_study_final_analysis.ipynb) is the single source of truth for selection, mixed follow-up, final scaling, and significance conclusions.

Superseded standalone rank, expert, mixed-follow-up, and old final-winner notebooks were removed to prevent conflicting conclusions. Their history remains available in Git.
