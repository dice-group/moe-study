# MoE Study Excel Workbooks

These five workbooks are the inputs to the analysis notebook:

- `moe_study_rank_sweep.xlsx`
- `moe_study_expert_sweep.xlsx`
- `moe_study_mixed_followup.xlsx`
- `moe_study_final_96_languages_2026-07-25.xlsx`
- `moe_study_final_200_languages_2026-07-25.xlsx`

Each workbook retains the pipeline report structure, including the `benchmark_raw` worksheet used by the analysis. The final workbooks contain the five trained configurations and the baseline.

The `further/` directory contains the compact audit, source-manifest, summary, and Markdown artifacts for the rank and expert sweep reports.
